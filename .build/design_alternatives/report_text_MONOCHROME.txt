1 Introduction

Our project examines how word meanings change over time. We will group occurrences that have similar meanings and compare how often these groups appear in different periods. We will work on SemEval 2027 Task 3, Subtask 1, which focuses on diachronic word sense induction. This is the subtask required for our course project (CS 445, 2026).

For each target word, the system receives sentences from different time periods. It assigns each occurrence to one or more sense groups, represented by integer labels. These labels must remain consistent across the periods of the same word so that we can follow changes in its usage. The task evaluates both the quality of these assignments and the changes in sense distributions between periods (SemEval 2027 Task 3 organizers, 2026).

The data preparation and exploratory analysis are complete. The notebook records the counts, quality checks and figures, and the official scorer has been tested with a simple prediction file. Three papers guide the method proposed below. We have not yet run the neural model or compared clustering methods.

2 Dataset Selection

We selected the official Swedish development dataset because it provides the inputs and reference labels needed for Subtask 1. This allows us to understand the data and check our evaluation process before considering further resources. The version used in this report was downloaded on 14 November 2026. We will initially work with this collection without adding another corpus or using the multilingual evaluation release.

Table 1 summarises the selected data. Each record contains a target word, a sentence identifier, the text, part of speech, a period label, character offsets and a year. The offsets locate the actual word form in the sentence. For example, a record for the lemma kvinna may mark the form kvinnor. We will preserve these spans when preparing model inputs. The definition file belongs to Subtask 2 and is outside our current scope.

3 Approach Plan

We propose a system that represents each target occurrence using its context and then groups similar occurrences. Giulianelli et al. (2020) provide the starting point for this approach. They use contextual word representations, cluster usages with K-means and compare the distributions of these groups over time. Their work guides our clustering plan, but it does not establish how well the same choices will work on the Swedish data.

Cassotti et al. (2023) introduce XL-LEXEME, a multilingual model trained to compare word meanings in context. We plan to use it as the first candidate for representing the target occurrences. Periti and Tahmasebi (2024) compare contextual representations for lexical semantic change. Their study will guide how we compare model choices and distinguish sense grouping from overall change estimation. All three papers were published in ACL or NAACL.

Method

First, we will mark the target span in each context according to the model’s input format and calculate its representation. If a context is too long, we will keep a window containing the target word. We will save the representations together with the model version and preprocessing settings so that later comparisons use the same inputs.

Next, we will collect all occurrences of each word across its observed periods and cluster them together. This allows the same group label to be followed over time. We will start with K-means and use silhouette scores to choose between 2 and 10 clusters, following the approach of Giulianelli et al. (2020). We will use repeated initialisations and fixed random seeds. This range may split a word that needs only one group or miss distinctions when more groups are needed. We will therefore include a single-cluster control and consider affinity propagation before finalising the method.

The first version will return one cluster label per usage in the required list format. Each output record will contain the word, sentence identifier and label list. We will later consider whether allowing more than one label improves the handling of ambiguous usages. We will also inspect example sentences from each predicted group to understand where the method makes mistakes.

Validation and evaluation

We plan to use five development folds, with two complete words held out in each fold and seed 445 used to generate the split. The remaining eight words will support parameter selection. The held-out words will keep all their periods, and their unlabelled usages will be clustered jointly without using reference labels. Since all words have already been examined during data analysis, these comparisons will be development results rather than independent test results.

For sense assignment, we will use the official BCubed precision, recall and F1 scores averaged across words. For sense dynamics, we will use the official Spearman correlation over eligible period transitions. The scorer divides a multi-label usage equally between its labels, compares adjacent observed periods with at least 10 usages each, and calculates base-2 Jensen–Shannon distance (ChangeIsKey, 2026). We will keep these settings unchanged. The final method will depend on the development comparisons, the quality of the predicted groups and the resources needed to run the model.

4 Next Steps

Our next step is to review the prepared data analysis and agree on the first experiment as a group. The current evaluation check assigns every usage of a word to a single cluster. It produces a BCubed F1 score of 0.7563. This result only checks that the prediction file and evaluation code work together; it does not measure a learned sense induction model. Its change predictions are constant, so Spearman correlation is undefined and the official scorer returns 0. Of 65 candidate period transitions, 60 pass the scorer’s minimum-count condition.

After reviewing this check, we will confirm the XL-LEXEME input format and resource requirements, calculate the representations and implement the initial clustering method. We will then compare clustering settings using the planned folds. If the model requires more memory than available, we will first reduce the batch size and reuse saved representations. If the clustering produces unclear groups, we will inspect their contexts and compare the alternative settings before adding more complex methods.
