1 Introduction

The project studies how a target word is used in different senses across historical periods. Our selected scope is SemEval 2027 Task 3, Subtask 1. The course requires Subtask 1 and leaves other subtasks optional [C]. We plan to induce sense groups from dated usages and evaluate both assignment quality and sense dynamics. No Subtask 2 model is included.

The technical unit is a target-word occurrence in context. A system assigns each occurrence one or more integer cluster identifiers. Identifiers have meaning only within a target word. This allows the same sense to be tracked across the periods in which that word appears. The current Codabench specification, rather than the older overview example, defines the input and output contract [T].

Completed preparation includes downloading the current Swedish development release, checking its schema and reference alignment, computing descriptive statistics, saving an executed EDA notebook, and running an integration diagnostic against the official scorer. The proposed neural method has not been trained or evaluated. All numerical observations in this report come from the released development data.

2 Dataset Selection

Selected data and rationale

We select the official Swedish development package downloaded on 14 November 2026 [T]. It provides task-matched inputs and public reference labels. We use no additional corpus at this milestone. This keeps the analysis traceable and avoids adding a second annotation scheme before the primary pipeline is understood. The multilingual evaluation release is not used.

Input fields are word, sentence_id, text, pos, period_label, start, end and year. The offsets identify a target surface form such as kvinnor for lemma kvinna. For Subtask 1 we exclude definitions.jsonl, which supports Subtask 2. We preserve the original text and offsets.

3 Approach Plan

Literature basis

All three methodology papers come from venues allowed by the course. Giulianelli et al. [1] represent word occurrences with BERT, cluster usages with K-means and study temporal distributions. Cassotti et al. [2] introduce XL-LEXEME, a multilingual model trained on word-in-context similarity. Periti and Tahmasebi [3] compare contextual representations and distinguish sense induction from aggregate change estimation. These motivate a contextual clustering pipeline, while leaving its performance on this release to be measured.

Proposed pipeline

1. Validate each target span and preserve the original text. If truncation is required, keep a window containing the marked target and record the truncation policy.

2. Encode each occurrence with the released XL-LEXEME model using its documented target-marking convention. Cache representations by data hash, model revision and preprocessing settings. This model is a candidate, not a completed experiment.

3. For each target word, pool usages across all its observed periods and cluster jointly. Start with K-means and silhouette selection over K = 2 through 10, inspired by [1]. Use fixed seeds and repeated initializations. Joint clustering keeps cluster identities consistent across time.

4. Compare a single-cluster control and an affinity-propagation candidate. Silhouette selection excludes K = 1 and can over-split a genuinely single-sense word. Evaluate this limitation explicitly rather than interpreting every cluster as a distinct dictionary sense.

5. Export one JSONL record per official usage with word, sentence_id and label, where label is a nonempty list of integers. A first version assigns one cluster; overlapping membership is a later extension.

6. Use the pinned official scorer to calculate assignment and temporal-change metrics. Inspect representative contexts from predicted clusters to explain errors.

Validation and reproducibility

We propose five development folds with two complete target words per validation fold, using seed 445. The remaining eight words support any supervised hyperparameter selection. The validation words keep all of their observed periods and their gold labels do not enter encoding or clustering. Joint clustering on their unlabeled usages reflects the intended transductive induction setting. All words have already appeared in descriptive EDA, so these are development comparisons, not untouched test estimates.

Report word-macro BCubed precision, recall and F1 for 1a. For 1b, follow the reference implementation: fractional sense counts, chronologically adjacent observed periods, at least 10 usages in both periods, and a global Spearman correlation over eligible word-period transitions [E]. The implementation uses base-2 Jensen–Shannon distance, the square root of divergence. We will preserve that implementation rather than silently substitute another formula.

The proposed contribution is a controlled comparison of representation and clustering choices, with analysis of multiple-label usages and uneven temporal coverage. This is a plan, not a claim of novelty or improved performance. The pretrained model, source methods and evaluator will remain explicitly attributed.
